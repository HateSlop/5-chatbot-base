# 프로듀서 시연 안내

[더뉴빌리지 공개 주소](https://chatbot-bb1234.onrender.com/)를 휴대전화나 컴퓨터의 브라우저에서 엽니다. 설치나 개발 도구는 필요하지 않습니다. 첫 접속에 화면이 늦게 뜨면 잠시 기다려 주세요. 무료 서버가 잠들었다가 다시 켜지는 중일 수 있습니다.

## 한 번 플레이해 보기

1. **마을로 이사하기**를 누르고 이름을 입력합니다.
2. 지미에게 자유롭게 말을 걸어 봅니다. 인물이 이야기 속 상황에 맞게 답하는지, 답변 옆 그림이 어울리는지 봅니다.
3. 화면의 **할 수 있는 일** 버튼을 누르며 캐런의 집, 정육점, 미용실을 방문합니다. 각 인물에게 같은 질문을 해 말투가 다른지도 봅니다.
4. 집으로 돌아온 뒤 캐시를 돕고 지미를 따라 정육점에 갑니다. 지하실 수첩을 발견했을 때 음식의 비밀이 벌써 드러나지 않는지 봅니다.
5. 지미가 약속한 다음 날 오후 6시부터 7시까지 오지 않으면 혼자 캐런의 집으로 갑니다. 사진을 찾고 집에 돌아오면 호감도에 따라 일자리 제안 또는 정육점 방문 요청이 나옵니다.
6. 정육점으로 가면 사망합니다. 일자리 제안을 받았다면 수락하거나 거절하고, 밥이 초대한 다음 날 축제 음식에서 머리카락을 찾은 뒤 **도망친다** 또는 **남는다**를 선택합니다.

**세 결말 종류:** 축제에서 남으면 마을에 동화됩니다. 차 키를 받고 도망치면 탈출합니다. 차 키 없이 도망치거나 낮은 호감도로 정육점에 가면 각각 다른 상황에서 사망합니다. 결말을 읽은 뒤 **새 이름으로 다시 시작**을 누르면 이름 입력 화면으로 돌아갑니다. 탈출을 보려면 사진 사건 전에 이웃을 돕는 대화를 여러 장면에서 해 보세요. AI가 대화 태도를 판단하므로 같은 문장만 반복해도 점수가 계속 오르지는 않습니다.

## 꼭 확인할 것

- 새로고침하거나 게임 화면을 떠났다가 돌아오면 이름 입력 화면이 나오는가? 같은 이름으로 다시 시작해도 이전 대화와 단서가 남지 않는가?
- 사건 직후 인물에게 “왜 그러셨어요?”라고 물었을 때 방금 한 말을 이어받고 같은 인사를 반복하지 않는가?
- 실제 인물의 대사가 자연스럽고, 성격이 서로 다른가? 지미가 사라지기 전에 결말을 미리 말하지 않는가?
- 대사 옆 그림, 장소 그림, 결말 그림이 보이고 장면에 어울리는가?
- 휴대전화에서 글을 읽고 버튼을 누르기 쉬운가?
- 오류가 났다면 다시 시도할 수 있는가? 오류가 난 시점과 화면 문구를 적어 주세요.

의견을 보낼 때는 **사용한 공개 주소, 기기, 어디까지 진행했는지, 기대한 모습과 실제 모습**을 적어 주세요. 비밀 키나 개인 정보는 보내지 마세요. 추가 확인이 필요한 항목은 [구현 현황](IMPLEMENTATION_SPEC.md)에 적혀 있습니다.
