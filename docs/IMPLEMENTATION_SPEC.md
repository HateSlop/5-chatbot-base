## 장면에 공통으로 적용되는 것

- **자유 대화:** AI는 현재 인물의 말투와 공개된 사건, 그 인물과 나눈 최근 대화를 참고한다. 장면 이동·단서·호감도·결말은 서버가 판정한다. 인물에게 아직 공개되지 않은 비밀은 답변에서 숨긴다.
- **호감도와 그림:** 마을 사람들은 하나의 호감도 수치를 공유한다. 답변의 표정 단서와 사건 규칙으로 캐릭터 그림을 고른다. 현재 이미지 선택에는 답변·이미지 설명의 임베딩 유사도 비교가 없다.
- **날짜와 기록:** 새 플레이를 시작한 한국 날짜의 월·일을 1955년에 놓은 날이 1일차이며 사건에 따라 5일차까지 진행한다. 날짜가 바뀌면 검은 화면에서 일 숫자가 넘어가고 왼쪽에 새 날짜가 표시된다. 새로고침·화면 이탈·결말 뒤 새 시작에서는 이전 플레이를 이어받지 않는다.
- **연출과 오류:** 큰 장소 그림 위에 인물이 나타나고, 장소별 음악·초인종·클릭음·짧은 암전을 사용한다. 대화 요청에 웹페이지 형태의 오류가 돌아오면 질문을 남긴 채 재시도를 안내한다.

## 확인 결과와 다음 작업

2026-11-10 로컬 자동 검사에서 서버 61개와 화면 145개가 통과했다. 프로듀서가 앞서 공개 주소에서 전체 시연 경로를 확인했으나 이번 변경은 아직 공개 배포 전이다. 자동 검사는 실제 AI 답변의 품질을 보증하지 않는다. 개발용 빠른 장면 확인은 `python scripts/preview_festival.py`로 할 수 있으며, 이 경로는 일반 배포에 등록되지 않는다.

1. 이번 로컬 화면·대사 변경을 `main`에 병합·배포한 뒤 공개 주소에서 날짜 전환과 두 캐릭터·낮은 호감도 경로·세 결말을 각각 확인한다.
2. 영상 첫 재생과 장소 이동을 현재 버전에서 다시 재고 [최적화](OPTIMIZATION.md) 계획에 따라 조정한다. 화면·영상·음악은 `yejoon` 담당이다.
3. 과제에서 요구하는 답변·이미지의 **임베딩 유사도 선택**은 아직 구현되지 않았다. 이미지 선택기 담당 `yejoon`과 방법·검증 기준을 정한다. 별도 DB는 현재 작은 고정 자료와 일회성 플레이에 필요하지 않다.

## 갱신 규칙

기능을 구현하거나 고칠 때마다 **같은 작업에서 해당 장면이나 공통 기능의 한 줄을 갱신**한다. 확인한 동작, 남은 시험이나 문제, 담당자를 쉬운 말로 적는다. 공개 배포 상태는 공개 주소에서 확인한 뒤에만 바꾼다. 날짜별 상세 작업 기록과 과거 검사 수치를 이 문서에 계속 덧붙이지 않는다.
