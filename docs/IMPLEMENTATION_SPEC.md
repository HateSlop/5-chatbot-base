## 갱신 규칙

기능을 구현하거나 고칠 때마다 **같은 작업에서 해당 장면의 한 줄을 갱신**합니다. 실제로 확인한 동작, 남은 시험이나 문제, 담당자를 쉬운 말로 적습니다. 확인하지 않은 기능을 완료라고 쓰지 않고, 공개 배포 상태는 공개 주소에서 확인한 뒤에만 바꿉니다. 날짜가 쌓이는 상세 작업 기록은 이 문서에 덧붙이지 않습니다.
