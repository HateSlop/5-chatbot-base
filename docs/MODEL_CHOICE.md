# 모델 선택과 답변 확인

OpenAI API 키는 운영진이 제공합니다. 처음에는 키 없이 데모 화면을 확인하고, 실제 모델을 연결한 뒤 같은 질문으로 답변 품질과 사용량을 비교하세요. 이 문서에는 가격표를 두지 않습니다. API 호출량과 테스트 범위는 운영진이 안내한 사용 기준을 따릅니다.

## 기본 설정은 GPT-6 Luna `none`

OpenAI 예시에서는 `gpt-6-luna`를 사용합니다. 별도 설정을 생략하면 Luna는 `medium` 추론 강도로 동작하므로, 응답마다 사용할 강도를 명시합니다. 이 베이스에서는 Luna가 지원하는 값 중 `none`, `low`, `medium`만 안내합니다. [GPT-6 Luna 모델 사양](https://developers.openai.com/api/docs/models/gpt-6-luna)

| 추론 강도 | 선택 기준 | 캐릭터 챗봇 예시 |
| --- | --- | --- |
| `none` | 모든 기능의 시작값이자 일반적인 기본 선택 | 인사, 일상 대화, 정해진 형식의 간단한 답변 |
| `low` | 같은 질문으로 평가했을 때 특정 기능의 맥락 반영이 부족하면 비교 | 앞선 대화나 캐릭터 설정을 함께 반영하는 기능 |

`medium`은 시작 설정에 넣지 않습니다. 여러 자료나 조건을 함께 판단해야 하는 특정 기능에서 `low`로도 명확한 요구사항을 충족하지 못한다는 평가 결과가 있을 때만 시험하세요. 같은 질문으로 비교해 실제 개선이 확인될 때에만 그 기능의 호출에 남깁니다.

`none`은 모델이 사라지거나 AI가 아니게 된다는 뜻이 아닙니다. 같은 Luna 모델이 답변을 만들되, 별도의 추론 작업을 적게 하도록 요청하는 설정입니다. 추론 강도는 답변 품질의 단계나 “더 잘하기” 버튼이 아닙니다. 높은 값이 모든 질문에 더 나은 결과를 주지는 않으므로, 기본값은 계속 `none`으로 둡니다. 특정 기능에서 반복적으로 확인된 문제가 있을 때만 `low`를 비교하고, `medium`은 `low`로도 요구사항을 채우지 못했다는 평가 근거가 있을 때 예외적으로 시험하세요. 개선이 확인되지 않으면 올린 강도를 유지할 이유가 없습니다. 한 번의 API 호출에는 하나의 강도를 지정합니다.

## 같은 질문으로 비교하기

캐릭터의 성격과 기획에 맞는 질문 10~20개를 준비합니다. 짧은 일상 대화부터 세계관 사실 확인, 설정에 없는 정보, 두세 턴의 대화까지 섞어 보세요. 각 설정에서 같은 질문을 실행하고 다음 항목을 기록합니다.

- 캐릭터 말투와 설정을 유지했는가?
- 사실을 잘못 만들거나 검색 자료와 다른 답을 했는가?
- 응답 시간과 답변 길이가 사용 흐름에 적절한가?
- API 응답의 입력·출력 토큰, 추론 토큰은 얼마나 달랐는가?

기록을 보고 실제로 품질이 나아진 기능에만 강도를 올립니다. 먼저 모든 질문을 `none`으로 평가하고, 문제가 반복되는 특정 기능에만 `low`를 적용해 비교하세요. `medium`은 그 `low` 평가에서도 해결되지 않은 복합 판단 문제에 한해 시험하고, 기준 질문에서 개선이 확인될 때만 해당 기능에 남깁니다. 전체 채팅의 기본 강도를 `low`나 `medium`으로 높이지 마세요. 호출별 설정 예시는 [OpenAI 모델 연결 가이드](MODEL_SETUP.md)에 있습니다.

## 사용량 확인하기

추론 토큰은 화면에 표시되지 않아도 생성된 출력 사용량에 포함될 수 있습니다. API 응답의 `usage.output_tokens_details.reasoning_tokens`를 확인해 설정별 차이를 비교하세요. `max_output_tokens`에는 추론과 화면에 보여줄 답변이 함께 포함될 수 있습니다. 한도를 너무 낮게 두면 눈에 보이는 답변이 거의 없이 응답이 끝날 수 있으므로, 응답 완료 상태와 사용량을 같이 확인합니다.

사용량을 기록할 때 질문 원문, 답변, API 키는 로그에 남기지 마세요. 테스트 횟수나 사용 범위가 걱정되면 운영진에게 먼저 확인합니다. [추론 강도와 토큰 사용 안내](https://developers.openai.com/api/docs/guides/reasoning?api-mode=responses)

## 로컬 모델은 별도 선택지

Ollama나 Gemma 같은 로컬 모델을 쓰면 OpenAI 키 없이 실행할 수 있지만, 팀이 모델을 실행할 컴퓨터나 서버를 준비하고 공개 서비스가 계속 접속할 수 있게 운영해야 합니다. Docker는 실행 환경을 묶어 줄 뿐 모델을 실행할 메모리나 GPU를 제공하지 않습니다. 공개 서비스의 기본 경로로 선택하기 전에 장비, 응답 속도, 동시 접속, 배포 환경을 확인하세요. [Ollama 실행 안내](https://docs.ollama.com/quickstart)
