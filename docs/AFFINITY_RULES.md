# 현재 사용 중인 호감도 규칙

> 2026-11-04 기준 서버 적용 규칙. 실제 AI의 분류 정확도는 별도 시연이 필요하다.

## 점수와 주민 태도

- 호감도는 모든 주민이 공유하는 한 점수다. 새 플레이는 **50점**에서 시작하고 **0~100점**에 머문다.
- **35점 미만**은 경계, **35~69점**은 평소, **70점 이상**은 환대 단계다. AI에는 단계만 전달하고 점수는 대사에 말하지 않도록 한다. 경계 단계에서도 인물 고유의 성격과 말투를 유지한다.
- AI는 **플레이어의 이번 발화 종류만** 분류한다. 답변의 친절함이나 표정은 채점 근거가 아니다. 점수와 일자리·결말은 서버가 결정한다.

## 대화 채점

| 분류 | 플레이어의 발화 | 기본 변화 |
| --- | --- | ---: |
| 호의 | 첫 인사, 감사, 안부, 상대의 일에 대한 관심, 예의 있는 질문·반응 | +5 |
| 협조 | 실제 도움 제안·약속, 요청 수락 | +7 |
| 중립 | 맥락 없는 짧은 반복, 사실 확인만 하는 말, 판단하기 어려운 말 | 0 |
| 적대 | 위협·모욕, 분명한 적대 행동, 거절 뒤에도 계속하는 압박 | 첫 감점 −2, 연속 두 번째 −4, 이후 −6 |

사건을 이해하려는 첫 질문과 근거 있는 추궁만으로 적대로 분류하지 않는다. 명시적 도움 약속이 없어도 자연스럽고 예의 있는 말은 호의로 분류하도록 AI에 지시한다.

호의·협조의 실제 상승폭은 **50점 이하에서 기본 변화량**이다. 50점보다 높으면 `반올림(기본 변화량 × (100 − 현재 점수) / 50)`으로 줄인다. Python의 `round()`를 사용하며 반올림 결과가 0이어도 최소 1점을 강제하지 않는다. 예를 들어 현재 점수가 50·70·90점일 때 호의는 각각 **+5·+3·+1**, 협조는 **+7·+4·+1**이다. 점수는 항상 0~100에 묶는다.

적대는 실제 감점이 있을 때만 연속 횟수를 올린다. 호의·협조가 실제 점수 상승으로 인정되면 연속 횟수를 한 단계 내리고, 중립은 바꾸지 않는다. 적대의 감점은 호감도가 높아도 줄어들지 않는다.

## 반복 방지

- 공백과 대소문자를 정리한 **같은 문장**은 플레이 전체에서 다시 채점하지 않는다. 중립으로 처리된 문장도 반복해서 점수를 받을 수 없다.
- 같은 장면·인물에서는 호의와 협조를 각각 한 단계로 다룬다. 호의를 먼저 인정한 뒤 협조하면 처음 호의를 받은 점수에서 계산한 **협조와 호의의 차이만** 더한다. 협조를 먼저 인정했다면 나중의 호의는 추가 점수가 없다.
- 서로 다른 적대 발화는 연속 감점할 수 있지만, 같은 장면·인물에서 실제 적대 감점은 **최대 3번**이다. 중복 문장이나 감점이 없는 0점 상태는 연속 횟수와 이 한도를 올리지 않는다.
- 플레이 전체의 대화 채점 횟수 제한은 없다. 이전 진행 토큰의 중복 채점 기록도 읽는다.

## 이야기 행동과 분기

| 이야기 행동 | 고정 변화 |
| --- | ---: |
| 미용실에서 캐시를 도움 | +5 |
| 정육점 지하실 수첩 발견 | −5 |
| 캐런의 방에서 지미 사진 발견 | −5 |

이 행동은 대화의 적대 연속 횟수를 바꾸지 않는다. 사진을 본 뒤 **집으로 돌아온 순간**의 점수가 **70점 이상**이면 캐런이 유통 운전 일을 제안한다. 수락해야 차 키를 얻고, 수락·거절 뒤 밥이 다음 날 축제에 초대한다. **70점 미만**이면 캐런이 정육점으로 부르며, 그곳에 가면 사망한다. 이 분기는 이후 대화로 점수가 바뀌어도 고정된다. 축제 경로에서는 마지막 선택과 차 키 보유 여부로 결말을 결정한다.

## 계산 경로 확인

서버 검사에서 각 대화 가능 장면에 한 번씩 서로 다른 말을 했을 때, 평범한 호의 대화 경로는 최종 **80점**, 적극 협조 경로는 **86점**, 연속 적대 경로는 **0점**이었다. 세 경로에는 캐시 돕기·수첩·사진의 고정 점수가 포함된다. 이 검사는 AI가 실제 발화를 올바르게 분류하는지 시험한 결과는 아니다.
