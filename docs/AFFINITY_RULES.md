# 현재 사용 중인 호감도 규칙

> 2026-11-04 기준. 이 문서는 현재 서버 코드에서 적용되는 규칙만 설명한다. 개선 아이디어는 아직 적용되지 않았다.

## 호감도가 뜻하는 것

- 호감도는 **마을 주민 전체가 플레이어를 대하는 태도**를 나타내는 하나의 점수다. 인물마다 따로 계산하지 않는다.
- 새 플레이는 **50점**에서 시작한다. 점수는 **0~100점** 안에 머물며 화면에 표시된다.
- 현재 점수가 **35점 미만**이면 주민에게 경계하는 말투를, **35~69점**이면 평소 말투를, **70점 이상**이면 환대하는 말투를 AI에 지시한다. 각 인물의 기본 성격과 말투는 유지한다. AI가 실제로 얼마나 자연스럽게 태도를 바꾸는지는 별도 시연이 필요하다.

## 자유 대화에서의 변화

AI는 답변을 만들면서 **플레이어가 방금 한 말**을 세 가지 중 하나로 분류한다. AI의 답변이 친절한지, 어떤 표정을 지었는지로 점수를 정하지 않는다. 서버가 분류 결과를 받아 다음 규칙으로 점수를 계산한다.

| 플레이어의 말 | 현재 분류 기준 | 기본 변화 |
| --- | --- | ---: |
| 협조 | 실제 도움을 약속하거나 협조함 | +3점 |
| 중립 | 인사, 단순 정보 요청, 반복 질문, 판단 근거가 부족한 말 | 0점 |
| 추궁·적대 | 근거 있는 추궁이나 적대적 행동 | −3점 |

기본 변화는 현재 점수에 따라 조금 줄어든다. 계산식은 `새 점수 = 0~100 범위로 제한(현재 점수 + 반올림(기본 변화 × (1 − |현재 점수 − 50| / 100)))`이다. 반올림은 Python의 `round()`를 따른다. 예를 들어 50점에서 협조하면 **53점**, 추궁하면 **47점**이다. 70점에서 협조하면 **72점**, 추궁하면 **68점**이다. 이 계산은 **50점에서 멀어질수록 상승과 하락을 모두 완만하게** 한다. 연속된 하락 횟수에 따른 가중치는 없다.

같은 말로 점수를 반복해서 얻거나 잃지 않도록 다음 제한을 둔다.

- 한 **장면·인물·분류** 조합에서 점수가 변하는 것은 한 번뿐이다. 같은 장면에서 같은 인물에게 다른 협조 표현을 해도 협조 점수는 다시 오르지 않는다.
- 앞뒤 공백, 연속된 공백, 대소문자 차이를 정리한 뒤 **같은 문장**이면, 다른 인물에게 말해도 다시 점수를 매기지 않는다.
- 점수가 실제로 변한 자유 대화는 **한 플레이에 최대 12번**이다. 중립 대화는 점수를 바꾸지 않으며 이 횟수에도 포함되지 않는다.

## 이야기 행동과 분기

다음 행동은 자유 대화의 분류와 별개로 정해진 점수를 적용한다.

| 이야기 행동 | 변화 |
| --- | ---: |
| 미용실에서 캐시를 도움 | +5점 |
| 정육점 지하실에서 수첩을 발견 | −5점 |
| 캐런의 방에서 지미의 사진을 발견 | −5점 |

사진을 본 뒤 **집으로 돌아온 순간**의 호감도가 **70점 이상**이면 캐런이 유통 운전 일을 제안한다. 이 결정은 그때 한 번 내려지며 이후 점수가 바뀌어도 뒤집히지 않는다. 일을 **수락해야** 차 키를 얻는다. 호감도가 낮다는 이유만으로 이야기 중간에 사망하지 않으며, 세 결말은 이후의 선택과 차 키 보유 여부로 정해진다.

## 현재 구현의 경계

- 평범한 인사나 질문은 중립으로 분류하도록 지시하므로, 자연스럽게 대화만 하면 호감도가 잘 오르지 않을 수 있다.
- 상승과 하락의 변화폭은 현재 점수에만 좌우된다. **초기 상승 보너스**와 **연속 하락 가중치**는 아직 없다.
- 인물의 대사 생성과 플레이어 발화 분류에는 AI가 관여하지만, 점수 계산·중복 방지·일자리 분기와 결말은 서버가 결정한다. 현재 검색 자료는 답변에 쓸 사실을 찾는 용도이며 호감도 규칙을 검색해 적용하지 않는다.
