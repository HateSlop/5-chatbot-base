# 지식 자료 자리

팀이 챗봇의 답변에 사용할 문서를 준비하는 곳입니다. 예시 경로일 뿐이므로 데이터 형식과 검색 저장소는 팀이 선택할 수 있습니다. 개인정보, 저작권이 확인되지 않은 자료, 실제 API 키는 넣지 마세요.

`example_lore.md`는 검색 흐름을 실험할 수 있는 가상의 작은 자료입니다. 이 폴더의 텍스트는 기본 데모 응답에 자동으로 반영되지 않습니다. 자료 검색은 `services/retriever.py`, 검색 결과를 활용한 답변 생성은 `services/generator.py`에서 구현하고, `services/chatbot_service.py`에서 연결합니다.
